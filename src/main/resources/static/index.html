Режимы работы

            
Обычный режим — вставьте код в текстовое поле (или перетащите файл), выберите шаблон и нажмите "Сгенерировать". Можно добавить контекстный код (DTO, зависимости) в нижнее поле — модель учтёт его при генерации, но документировать будет только главный код.

            
Проектный режим — загрузите папку с проектом через кнопку "Загрузить папку с проектом". Отметьте файлы чекбоксами, затем кликайте по номерам строк в предпросмотре чтобы выделить фрагмент (первый клик — начало, второй — конец). Отметьте один фрагмент как главный (документируемый код) — он подсветится красным. Остальные фрагменты будут контекстом (синяя подсветка). После выбора нажмите "Сгенерировать".


            
Шаблоны документа

            
211 — документ со структурой: входные данные → выходные данные → ошибки. Требует заполнения дополнительных параметров (алгоритм, описание, ссылка, полномочия, SLA p95/p99).

            
230 — общие сведения + алгоритм работы. Подходит для описания процессов и бизнес-логики без строгой структуры входов/выходов.


            
Предпросмотр промта

            
Перед генерацией можно нажать "Предпросмотр промта" — откроется окно с финальным промтом, который будет отправлен модели. Проверьте, что вся нужная информация попала в промт, и нажмите "Сгенерировать".


            
Результат генерации

            
После генерации отображается результат. Доступны действия:

            
    
                
  • Код / Просмотр — переключение между сырым XHTML и визуализированным предпросмотром.
    • 
                
  • Копировать — скопировать XHTML в буфер обмена.
    • 
                
  • Скачать — выберите формат: HTML, MD (Markdown), PDF, DOCX.
    • 
                
  • Версии — каждая генерация и исправление создают новую версию. Можно переключаться между ними (v1, v2, ...).
    • 
                
  • Исправить — напишите что изменить (например "убери раздел про исключения") и модель доработает документ, создав новую версию.
    • 
            


            
Управление чатами

            
    
                
  • Новый чат — кнопка "+" в боковой панели. Выберите режим (обычный или проектный).
    • 
                
  • Переключение — клик по чату в списке слева.
    • 
                
  • Переименовать — двойной клик по названию чата или кнопка с карандашом. После первой генерации чат переименовывается автоматически (по первой строке кода или имени файла).
    • 
                
  • Закрепить — кнопка с булавкой слева от названия. Закреплённые чаты отображаются в верхней части списка.
    • 
                
  • Удалить — кнопка с крестиком.
    • 
            


            
Горячие клавиши

            
    
                
  • Enter (в поле имени чата) — сохранить новое имя.
    • 
                
  • Escape (в поле имени чата) — отменить переименование.
